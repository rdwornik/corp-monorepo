# 2026-05-18 — Retire single-file handoff (docs/HANDOFF.md + scripts/update_handoff.py)

Type: Decision note (NOT a numbered ADR — ADR-numbering hygiene is a
later rollout step; corp-monorepo currently has two ADR-27 files).
Status: Accepted
Date: 2026-05-18
Branch: `docs/handoff-retirement`
Authority: 2026-05-18 universalization-review audit §2.7, §2.13;
universalization rollout step 2.

## What

Retired the corp-monorepo-local single-file handoff mechanism:

- `docs/HANDOFF.md` (456 lines, "Corporate OS — Master Session
  Handoff", regenerated by the script below).
- `scripts/update_handoff.py` (the regenerator; its sole consumer
  was `docs/HANDOFF.md`).

Live content rehomed to `BACKLOG.md` at repo root (created same day).
CLAUDE.md §"Session Handoff" rewritten to point at the ecosystem
handoff convention defined in `.dev-knowledge`.

## Why

- The master-file pattern predates the ecosystem handoff spec. The
  going-forward convention is folder-per-session bundles generated
  and stored in `.dev-knowledge` (ADR-42 +
  `.dev-knowledge/protocols/HANDOFF_PROCESS.md`), NEVER written into
  target repos (ADR-36 read-only contract).
- The file was ~7 weeks stale at retirement time: last
  content-bearing commit 2026-03-29; rename-only commit 2026-03-30;
  the regenerator only refreshes counts/timestamps, not content
  structure. Many references inside the file pointed at
  `.ecosystem/` paths removed 2026-03-30 and at `decisions/` instead
  of `docs/decisions/`.
- The only load-bearing content was §"Open Decisions" + §"Pending
  Fixes" — both rehomed to `BACKLOG.md` in the same branch (Step 1)
  before deletion (Step 2). All other sections were stale dated
  snapshots or duplicates of authoritative content elsewhere
  (CLAUDE.md, ARCHITECTURE.md, `docs/decisions/`, CLI help) and are
  preserved in git history.

## Decommission

- `docs/HANDOFF.md` — removed via `git rm` on branch
  `docs/handoff-retirement`. Last commit touching the file before
  removal: `d2d2fdf` (2026-03-30 rename from `MASTER_HANDOFF.md`).
- `scripts/update_handoff.py` — removed via `git rm` on branch
  `docs/handoff-retirement`. Sole consumer was `docs/HANDOFF.md`;
  the script has no remaining call sites.
- `CLAUDE.md` §"Session Handoff" — rewritten to point at the
  ecosystem convention (no replacement mechanism inside this repo).

## What replaced it

The ecosystem handoff flow in `.dev-knowledge`:

- **Where bundles live:**
  `.dev-knowledge/docs/handoffs/{YYYY-MM-DD}-corp-monorepo-{type}/`
  (flat 11-file folder; type defaults to `session-sync`).
- **Trigger:** in Claude Code at `.dev-knowledge`, the operator
  says "Make handoff for corp-monorepo" (Stage 1) → pastes the OLD
  browser chat response into `stage2-response.md` → says "Complete
  handoff for corp-monorepo" (Stage 3).
- **Spec:** `.dev-knowledge/protocols/HANDOFF_PROCESS.md`
  (operational) + `.dev-knowledge/docs/decisions/ADR-42-handoff-format-v3.md`
  (authority).
